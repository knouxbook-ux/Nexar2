## 🏗️ Running the Project

### Prerequisites
```bash
node >= 18
pnpm >= 8
expo-cli >= 6
```

### Install Dependencies
```bash
pnpm install
```

### Configure Environment
```bash
cp .env.example .env
# Edit .env with your real keys:
# DATABASE_URL, OPENAI_API_KEY, FIREBASE_*, STRIPE_*
```

### Run (Web / Expo Go)
```bash
pnpm dev
# or
npx expo start --web
```
> **Note:** Screen recording, audio capture, and FFmpeg processing will NOT work in Expo Go or web. See Native Build section below.

## 📱 Native Android Build (Required for Screen Recording)

```bash
# Step 1: Generate native Android project
npx expo prebuild --platform android

# Step 2: Build via EAS (Testing APK)
eas build --platform android --profile preview

# Step 3: Production APK
eas build --platform android --profile production
```

### EAS profiles are configured in `eas.json`.

## ⚠️ Features Requiring Native Build

| Feature | Reason | Status |

| Camera (Multi-cam) | expo-camera native | ⚠️ Limited in Expo Go |
